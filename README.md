# 84ui2 studio

Static first prototype for the 84ui2 studio image gallery.

## Current prototype
- Gaming / Nature / Photography filters
- Responsive masonry gallery
- Image lightbox
- Drag & drop / local image preview
- 84ui2 studio branding and uploaded logo

## Important
The current Upload button previews images in the browser only. It does NOT permanently upload them to an online server yet.

Next phase:
1. Add real user/admin authentication.
2. Add permanent image storage.
3. Add an admin dashboard for uploading/deleting images.
4. Add image metadata, tags and individual share pages.
5. Deploy on a free hosting provider.
